# 使用手册

[返回首页](../README.md)

## 启动与权限

NetMetric 支持 Windows 10 1809+ / Windows 11 x64，当前只监控和修改 IPv4。

发行版 exe 自带 Python 和 Python 第三方库；网络读取仍使用 Windows 的 WMI，修改与配置回读调用系统自带的 Windows PowerShell 5.1 和 NetTCPIP 模块。无需安装 Conda、Node.js 或其他第三方应用。源码运行的前期准备见 [README](../README.md#从源码运行)，完整清单见 [依赖说明](dependencies.md)。

| 程序 | 权限与行为 |
| --- | --- |
| `NetMetric.exe` | 启动时请求管理员权限，允许修改接口度量 |
| `NetMetric-ReadOnly.exe` | 普通权限下只读监控，可点击「以管理员重启」后编辑 |

两版功能相同，差别是启动权限清单；程序共享单实例锁。拒绝标准版的 UAC 后，Windows 不会启动程序；需要普通权限监控时使用免提权版。源码启动默认以当前权限运行。

## 理解表格

**有效度量 = 接口度量 + 路由度量。** 对同样具体的路由，数值越小，优先级越高。

- **接口度量**：整个接口的优先级，由系统自动计算或手动设置。
- **路由度量**：某条路由本身的度量。主表显示该接口最优默认路由的值。
- **有效度量**：两者之和。默认出口按已连接接口的默认路由比较；存在等价路由时显示所有候选。
- **自动跃点**：是否由 Windows 自动计算接口度量，与 DHCP 是否启用无关。
- **默认网关**：存在多个默认网关时，显示有效度量最低的一条；路由详情保留所有条目。
- **缺失值**：`—` 表示无对应路由或暂时无法一致地推导度量。

绿色表示已连接且有默认路由，黄色表示已连接但没有默认路由，灰色表示未连接。顶部统计始终对应全部接口，筛选只改变表格内容。

## 监控与布局

- 筛选支持全部、已连接、未连接和有默认路由。
- 搜索支持名称、网卡描述、接口索引、IPv4 地址与网关。
- 点击表头排序；度量、路由数等按数值排序。
- 拖动表头分隔线调整宽度，双击分隔线适配单列。表头右键菜单和「列宽」菜单还提供按内容适配、适配窗口、输入像素值及恢复默认列宽。
- 列宽和「路由度量」列的显示状态会自动保存，下次启动恢复。
- 暂停保留最后一帧，仍可筛选、手动刷新和修改。写入期间后台串行处理命令，完成后刷新实际状态。

## 修改接口度量

1. 以管理员权限启动，选择一个已连接的接口。
2. 双击「接口度量」，或点击「修改接口度量」。
3. 输入 1–9999 的整数，按 Enter 提交；Esc 取消。
4. 确认接口名称和修改前后的值。程序写入后回读活动、持久配置，确认设置生效。

手动指定度量会关闭自动跃点，修改会持久保存。右键菜单支持度量 ±5/±10、恢复自动跃点、复制接口信息和查看路由。

「设为首选」把所选接口度量设为 10，并根据有效度量调整其它已连接的默认路由接口，避免修改后仍打平。确认框列出全部改动；无法在合法范围内达到目标时拒绝操作。

## 恢复与撤销

- 「恢复自动跃点」交回 Windows 计算度量，恢复后的数值可能与之前不同。
- 「变更记录」保留本次会话最近 50 条操作；「撤销上一次」恢复上次成功修改前的手动度量或自动模式。
- 修改和撤销前会检查接口身份、连接状态和当前值。如果外部程序已改动设置，程序会停止操作并提示刷新。
- 部分写入失败时，会尝试恢复已经操作的接口；恢复失败会列明原因。退出程序后不会保留撤销记录。

## 验证选路

点击「立即验证选路」，输入目标 IPv4 地址。程序调用 Windows 选路 API，显示所选接口、匹配路由和下一跳，不发送探测流量。

主表的默认出口只比较默认路由。VPN 的更具体路由、应用绑定、系统代理和 IPv6 均可能采用不同出口。度量调整主要影响后续新建连接，必要时重新建立浏览器、代理等应用的连接。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| F5 | 手动刷新 |
| Ctrl+F | 聚焦搜索 |
| Ctrl+Z | 撤销上次成功修改 |
| Enter / Esc | 提交 / 取消单元格编辑 |

## 配置与排错

- 日志：`%LOCALAPPDATA%\NetMetric\netmetric.log`，自动轮转。
- 布局：`%LOCALAPPDATA%\NetMetric\ui.json`，只保存列宽和列显示偏好。
- 修改失败时，查看「变更记录」的完整结果和日志，确认失败发生在系统写入、活动配置校验还是持久配置校验。VPN 等服务可能覆盖接口设置。
- 采样失败时保留上次数据，并显示告警、自动重试；此时表格内容可能已经过期。

如需导出只读诊断，在项目目录运行：

```powershell
.\dist\NetMetric-ReadOnly.exe --diagnose --output snapshot.local.json
.\dist\NetMetric-ReadOnly.exe --self-test --output gui-check.local.json
```

`--self-test` 会启动完整界面，确认首帧后自动退出。诊断文件包含本机接口和地址信息；提交问题时按需去除个人网络信息。这些 `.local.json` 输出已被项目的 Git 忽略规则排除。
